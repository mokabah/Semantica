# Roadmap

The roadmap is a plan, not a record of completed work. Only v0.1.0 exists.

| Version | Theme | Intended content |
| --- | --- | --- |
| v0.1 | Basic semantic preservation evaluation | **Released.** Rule-based checks, report, benchmark |
| v0.2 | Advanced proposition representation | Richer argument structure, nested clauses, a held-out benchmark split |
| v0.3 | Contextual meaning analysis | Paragraph context, an interface for coreference resolvers |
| v0.4 | Pragmatic and discourse analysis | Discourse relations, a wider set of speech acts |
| v0.5 | Epistemic fidelity evaluation | Evidentiality, scope of modality and negation |
| v0.6 | Advanced paraphrase verification | Optional entailment and AMR-based comparison behind the model interface |
| v0.7 | Controlled paraphrase generation | Generation conditioned on the verifier's feedback, kept as a separate component |
| v0.8 | Multilingual semantic analysis | Language-specific resources and an evaluation per language |
| v0.9 | Human evaluation framework and research benchmarks | Annotation guidelines, agreement reporting, independently labelled sets |
| v1.0 | Stable research toolkit | Stable API and documented validation results |

Each release is expected to update `docs/LIMITATIONS.md` and report any new result with its
denominator.
